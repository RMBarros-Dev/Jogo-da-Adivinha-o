# Diretrizes de identidade visual — Jogo da Adivinhação

## Posicionamento

Projeto educacional de console para praticar lógica, validação de entradas e orientação a objetos em C#. A identidade deve comunicar raciocínio, tentativa e descoberta, sem sugerir um produto online ou uma plataforma de jogos.

**Assinatura:** Pense. Compare. Descubra.

## Conceito visual

O símbolo combina um alvo geométrico incompleto com um ponto de interrogação. O arco representa aproximação progressiva; o centro representa a descoberta. A construção evita ícones genéricos de videogame e mantém legibilidade em tamanhos reduzidos.

## Ativos

- `assets/brand/logo.svg`: símbolo principal para fundos escuros.
- `assets/brand/logo-light.svg`: símbolo para fundos claros.
- `assets/brand/banner.svg`: banner horizontal para README e apresentação do repositório.
- `assets/brand/project-mark.svg`: assinatura horizontal com símbolo, nome e tagline.

## Regras de aplicação

- Preservar proporções e área de respiro dos SVGs.
- Não aplicar sombras, contornos ou gradientes adicionais sobre os ativos.
- Utilizar a versão clara em fundos marfim e a versão principal em fundos escuros.
- Manter contraste suficiente para leitura em telas pequenas.
- Não usar a identidade para sugerir multiplayer, conectividade, persistência ou recursos não presentes no projeto.

## Escopo técnico representado

A comunicação visual reflete somente o que está documentado no repositório: jogo de terminal em C#/.NET 10, número secreto entre 1 e 100, até cinco tentativas válidas, dicas de maior/menor e projeto de testes separado.
